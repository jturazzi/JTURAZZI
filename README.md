## 👋 About me

I'm an **IT Manager** who likes to build the tools my users actually need, instead of waiting for them to exist.

Most of what I publish here comes from real day-to-day needs: web apps for internal workflows (forms, meetings, onboarding, inventories), integrations with **Microsoft 365** and **Active Directory**, monitoring dashboards, and a lot of shell and PowerShell automation to keep servers and workstations tidy.
